# Technologies and Libraries

## Backend
- **Runtime**: Deno (Supabase Edge Functions)
- **Database**: PostgreSQL (Supabase)
- **Framework**: Supabase standard server-side TS

## Frontend
- **Framework**: React 18
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Language**: TypeScript

## Key Libraries
- **@supabase/supabase-js**: Database and Auth interaction.
- **lucide-react**: Icons.
- **sonner**: Toast notifications.
- **zod**: Schema validation (if used).
